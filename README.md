# PayLock Live Test-Only Evidence

This private repository retains **redacted evidence records** for isolated, test-only PayLock runtime exercises. It intentionally excludes raw H0/H1 values, endpoint URLs, request headers, API keys, response bodies, provider secrets, and unredacted delivery payloads.

The evidence package currently covers a 22 August 2026 Cherry-hosted runtime exercise. It used only synthetic fixtures and simulated receipts. It did not create a payment, contact a payment processor, register a webhook, change production configuration, deploy code, or involve a real customer.

See [`evidence/cherry-paylock-test-only-20260822/`](evidence/cherry-paylock-test-only-20260822/) for the bounded claim matrix, normalized result tables, provenance pin, and integrity record.
